# Desafio-V360-Conector-de-Pedidos-de-Compra-
API REST para o Desafio Técnico V360: camada intermediária de integração backend que ingere pedidos de compra em formatos variados de múltiplos clientes, normaliza os dados para um modelo/contrato único e padronizado e os envia à plataforma V360, mantendo o produto principal desacoplado e escalável ante a entrada de novos clientes.
